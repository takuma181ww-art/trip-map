# TakuVLOG トラベラー(旧: 旅のしおりマップ)

旅行の予定カードと地図(OpenStreetMap)が連動する1枚のページ。GitHub Pages で公開している。旅行をいくつもためて、左上のプルダウンで切りかえる(過去の旅行も、これから行く旅行も)。

- `index.html` … ページ本体。データを読んで表示するだけ(ふだんは触らない)
- `data/trips.json` … 旅行の一覧(`id`・`name`・`start`・`end`)。左上のプルダウンに出る
- `data/trips/<id>/day1.json`, `day2.json` … その旅行の日ごとの予定。日を足す時は次の番号のファイルを作る。番号は1から飛ばさずに続ける。ファイルがまだない日は、`start`〜`end` から空の日として出る
- 開いた時に出る旅行: 旅行の日ならその旅行 → これから行くいちばん近い旅行 → 最後に見た旅行。リンクは `?trip=<id>&day=day2`。前のリンク(`?day=day2` だけ・何もなし)もそのまま開ける
- 右上の ＋ … 行き先・日にち・名前・行きたい所を入れると、その端末の中だけに「下書き」の旅行ができる(すぐ選べる)。下書きの「Claude に頼む文をコピー」を Claude Code に貼ると、下の「旅行を足す時」の手順で公開の旅行になる。同じ名前・同じ1日目の旅行が `trips.json` に入ると、下書きは自動で消える
- 地図に自分の位置(GPS)を青い点で出す。旅行の当日は開いた時から、ほかの日は地図右上の 📍 を押した時から。📍 を押すと自分の位置へ移動する
- 韓国の場所のある予定には「ここへ行く」の 🚶徒歩/🚇電車・バス/🚕タクシー ボタンが出る。時間は現在地(なければ1つ前の予定)からの直線距離で出した目安。押すと NAVER の経路がその手段で開く。おすすめは 1.2km まで徒歩、15km まで電車・バス
- 場所のある予定には「✓ 行けた/行けなかった」ボタンが出る。旅行の当日は、GPS で予定の場所から 150m 以内に入ると、いちばん近い1つを自動で「行けた」にする(マップを開いている間だけ)。記録はその端末だけに残り、上の帯から全日の一覧を出してコピーできる
- 旅行の当日は、カードに「ここから再開」ボタンが出る。押すとそのカードを今の時刻にして、後ろの予定も同じだけずらす(飛ばした予定はそのまま)(その iPhone の中だけに覚える。データの JSON は変わらない)。上の帯を押すと元に戻る
- ページ上部に日の切りかえが出る。旅行の当日は、どのリンクから開いても今日の日を出す。上の日付ボタンで選び直した時だけ、その日を出す。旅行の日以外は、その旅行で最後に見た日を出す

## 日常の画面(2026-11-19〜)

旅行と同じ地図とカードで、毎日の「行きたい場所」を出す画面。いちばん上のタブ「✈︎ 旅行 / 🏠 日常」か、上の帯を左右にスワイプで切りかえる。

- 開くといつも今日の日付。日の切りかえは昨日〜1週間後(行きたい場所がある日は「・件数」)。リンクは `?mode=daily&date=2026-11-20`
- 開いた時の画面: リンクの指定 → 旅行の当日は旅行 → 最後に開いた方 → 日常
- カードの上の欄に行きたい場所を入れて「探す」→ 候補(OpenStreetMap の Nominatim。今いる所の近くを先に)から選ぶと足せる。時間・メモも付けられる。見つからない時は「場所なしで足す」か、Google マップで探して座標(35.68, 139.76 の形)を貼る
- 時間のある予定は時刻の順、時間なしはそのあと。カードの「消す」で消す。行けた・行けなかった・GPS で近くに来たら自動で「行けた」は旅行と同じ
- 旅行の画面にも同じ入力枠がある(2026-11-19〜)。足した場所はその日の予定に時刻の順で混ざり、「この iPhone だけ」の札と「消す」が付く。保存は localStorage の `trip-extra`(キーは「旅行の id|日付」)で、公開の `dayN.json` は変わらない。正式に入れる時は Claude に頼む
- **出る時刻**: 場所と時刻のある日常の予定には「10:44 に出る(11:40 に着くには・電車で約46分+余裕10分・目安)」が出る。着きたい時刻は `arrive`(なければ `time`)。今いる所(GPS)からの直線距離の目安(1.2km までは徒歩 75m/分、それより遠ければ 10分+道のり 900m/分)なので、正しい時間は横の「Google マップの経路で確かめる」で
- **Google カレンダーとつなぐ**(2026-11-19〜。いちばんの置き場): 日常の画面の「📅 Google カレンダーとつなぐ」で Google にログインすると、そのアカウントのカレンダーの予定がカード・地図に出る(青い「個人」=自分のメイン、緑の「ファミリー」)。入力枠で足す時は「個人/ファミリー/この端末だけ」を選べ、カレンダーの予定として入る(場所の位置は予定の extendedProperties.private の lat/lng に入れる)。iPhone・iPad・PC のどれでも同じ。ログインは Google のページへ行って戻る形(response_type=token。窓は使わない)。つながりは1時間で切れるが、開いた時に1回だけ見えないつなぎ直し(prompt=none・login_hint はメインのカレンダーの id)をして、Google の画面を出さずに戻る。通らない時(許可の取り消し・Google のログアウト)だけ帯を押してもらう
  - Google Cloud: プロジェクト `takuvlog-traveler`(Taku のアカウント)。Calendar API オン。OAuth は「外部・テスト中」で、使えるのはテストユーザーに入れた Taku と奥様だけ(人を足す時は「Google Auth Platform → 対象 → テストユーザー」)。クライアントは「TakuVLOG Traveler web」(ウェブ)。生成元 `https://takuma181ww-art.github.io` と `http://localhost:8799`、リダイレクト URI `https://takuma181ww-art.github.io/trip-map/` と `http://localhost:8799/`。index.html の `GOOGLE_CLIENT_ID` がこのクライアント ID(公開してよい値)
  - **行き先はこれですか?**: 場所の入っていない予定は、カードで予定の名前から候補(Nominatim・今いる所の近くを先に)を出して聞く。押すとカレンダーの予定に「場所」と位置(private の lat/lng)を書き戻すので、どの端末でも次から聞かない。「ほかを探す」は検索シートを「行き先を決める」形で開く(シートの中で名前を変えて探し直せる)。「場所はない」は private の noPlace=1。読むだけのカレンダーは端末に覚える(`gcal-place-fix`)。OpenStreetMap には個人のお店が少ない(「リストワール山本」は出なかった)
  - **お店さがしは Google の場所の検索**(2026-11-19。Places API (New) の Text Search):`PLACES_KEY`。今いる所のまわり 8km を優先し、近い順に並べ、いちばん上に「いちばん近い」。種類(洋菓子店・歯科医院など)も出す。この端末で1日 60回(`PLACES_DAILY_MAX`)を超えたら OpenStreetMap で探す。料金は Text Search Pro で月 5,000回まで無料、その先 1,000回 $32(2026-11 に Google の料金表で確認)
    - 鍵の守り: 使える API は Places API (New) だけ、使える場所は `https://takuma181ww-art.github.io/*`(Taku の GitHub のページだけ)と `http://localhost:8799/*` だけ。検索の fetch は `referrerPolicy: 'no-referrer-when-downgrade'` でページの住所を最後まで送る。ただし iPhone の Safari は追跡を防ぐ仕組みで、何を指定しても「takuma181ww-art.github.io/」までに短くするので、鍵の許可は `takuma181ww-art.github.io/*` にしてある(trip-map/* だけにすると iPhone で断られて(403)お店が出なかった。2026-11-19)(Google Cloud → 認証情報 → Maps Platform API Key)。SearchTextRequest per day の割り当ては無料トライアル中は変えられなかった(75,000 のまま)ので、有料に切り替える時に 100 に下げる
    - お支払い: プロジェクトは無料トライアルの請求先アカウント(01903B-…、90日・¥47,462 のクレジット)につないである。トライアル中は請求されない。予算アラート ¥1,000(50/90/100/150% で Taku の Gmail へ)。別に有料の請求先アカウント「請求先アカウント 1」(01F0C8-…、前払い ¥3,800 保留中・どこにもつないでいない)がある
  - **1日の予定(大きな画面)**: 日常のカード(または空の日の「大きな画面で1日の予定を組む」)を押すと全画面で開く。スマホは上に地図・下にリスト、幅 760px 以上は左にリスト・右に地図。その日の予定が時刻順に並び、場所のない予定は行の中で候補(地図に A・B…)から「これ」で決める・「名前を変えて探す」・「場所はない」。上の欄で探すと結果がリストと地図(青い番号)に出て「＋足す」で時間と入れる所(個人/ファミリー/この端末だけ)を選んで続けて足せる。閉じると、いつもの画面を読み直す。同じ言葉の検索はその画面を開いている間は覚えて、Google の回数を使わない
  - **地図を長押し**(大きな画面): その地点にピンを立て、「ここを足す」か「選んでいる予定の場所をここにする」。住所は OpenStreetMap の reverse で添える。長押しで決めた場所は private の exact=1 で、Google マップ・経路は住所ではなく座標で開く(駐車場など、点の位置で行き先が変わるため)。カードの経路は 🚇 電車と 🚗 車
  - **前の予定から**(2026-11-21): 場所のある日常の予定で、1つ前に場所のある予定(「◯◯のあと」ならその予定)があると、カードに「クラーチ → ここ:🚗約◯分・🚇約◯分(目安)」と「🚇/🚗 前の予定から」が出る。押すと Google マップが、前の予定を出発地にした経路で開く(現在地からの経路はその上の「電車の経路・車の経路」)。出発地は住所の文字ではなく座標で渡す(文字だと iPhone の Google マップが出発地を読み落として現在地からの経路になったため)
  - **「◯◯のあと」**: 時間を空けて足すと、いちばん下の予定のあとに入る(private の after=前の予定の id、カレンダーには前の予定の終わりの時刻で仮に入れる)。トラベラーでは時刻の代わりに「◯◯のあと」。前の予定が終わったら(行けた・終わる時刻を過ぎた)カードに「今から行くと 🚗約◯分・🚇約◯分」、まだなら「◯◯が終わったら(◯時ごろ)出発」。大きな画面の行の左の ≡ をドラッグで並べかえ(動かした予定はすぐ上の予定のあとになり、下の「あと」の予定と仮の時刻を順につなぎ直す)。書き戻す時は private のほかの印を残す
  - 1日60回の歯止めに届いたら、一言出して無料の地図の検索に切り替える(本当の枠は Google の無料の月 5,000回。足りない日が続くなら月単位の枠にする)
  - 予定の場所(文字)の位置は Nominatim で探して端末に覚える(`geo-cache`)。見つからない時は印なしで、Google マップは住所で開く
- **カレンダーなどから取り込む**: `?mode=daily#add=<base64url の JSON>` を開くと、その予定を日常に足す(同じ日・名前・時刻はだぶらせない)。JSON は `[{date, name, time, arrive, memo, lat, lng, googleQuery, note}]`。「#」より後ろはサーバーに送られないので、予定の中身は公開されない。Claude はカレンダーの予定(場所あり)からこのリンクをつくって Taku に渡す。iPhone のショートカットから毎朝つくる案もある(未着手)
- **日常の行き先はその端末の中(localStorage の `daily-plans`)だけに保存する。data/ には入れない**(このページは誰でも見られるので、毎日の行き先を公開しないため)。iPhone を替えたり Safari のデータを消すと消える

## 旅行を足す時(Claude へ: この手順で)

1. 作業の前に必ず `git pull`(iPhone の Claude Code から直接コミットされることがある)
2. `data/trips.json` の `trips` に1件足す: `id`(`2027-05-korea` のように 年-月-行き先 の英小文字。あとで変えない)・`name`(「2027年5月 韓国旅行」のように。下書きから頼まれた時は下書きと同じ名前)・`start`・`end`("2027-05-02" の形)
3. `data/trips/<id>/` を作り、`day1.json` から日ごとに入れる(形は下の「予定を変える時」と同じ。`title` は「韓国旅行 1日目」、`date`・`weekday`・`utcOffset`・`items`)。予定が決まっていない日は作らなくてよい(空の日として出る)
4. 予定は行き先を調べて、案を Taku に見せてから入れる
5. JSON がこわれていないか確かめて、`main` にコミットして push

## TakuVLOG トラベルリストと合わせる(Claude へ: 必ず)

行きたい所・行ったお店をためる大元は **TakuVLOG トラベルリスト**(claude.ai のドキュメント https://claude.ai/artifact/HZNGtJLiCRvY4gPHo4CAnL 。ログインした Taku だけが見られる)。

- トラベラーに場所のある予定を足したら(「今日の予定に足して」「ここに行きたいからトラベラーに入れて」など)、**同じ場所をトラベルリストの該当エリアにも足す**。形はリストの書き方に合わせる: エリアの見出しの下に「[店名](Google マップ) … いつ・何の予定か・住所・営業時間・メモ。[NAVER](韓国のみ)」。もうある店なら、メモに日付と「行く予定」「行った」を書き足すだけ
- 行けた(✓)が分かったら、リストのその店に「行った(日付)」を書く
- リストに書くのは Claude Docs の道具(connector)を使う。使えない所(iPhone のクラウドの Claude Code など)では、トラベラーだけ直して「トラベルリストにはまだ入れていない」と Taku に伝える。次に Mac の Claude が README を読んだ時に、足していない分をそろえる
- 自宅の位置・予約番号などはリストにも書かない(リストは非公開だが、トラベラーと同じ決まりにする)
- ホーム画面の入り口: `list/`(押すとリストを開くだけのページ。アイコンは `list/apple-touch-icon.png`)。置く時は `https://takuma181ww-art.github.io/trip-map/list/?setup` を開いて「ホーム画面に追加」

## index.html を直した時(Claude へ: 必ず)

- `index.html` の最後の方にある `const BUILD = '…'` を新しい値(日付-内容)に変える。開いた時に公開中の BUILD と見比べ、違えば1回だけ自動で読み直す(iPhone の Safari が古い版を最大10分ほど覚えていて、直した版がすぐ出なかったため。2026-11-19)。開いたままでも、画面に戻ってきた時(1分に1回まで)に同じく確かめる
- `data/` の JSON だけを変えた時は変えなくてよい(JSON は毎回読み直している)

## 予定を変える時(Claude へ: この手順で)

1. 変えるのは `data/trips/<id>/dayN.json`(と旅行の日にちが変わる時は `data/trips.json`)だけ。`index.html` は触らない
2. 1件の形:
   - 場所のある予定: `no`(印の番号)・`time`("16:30" の形)・`name`・`country`("jp" / "kr")・`lat`・`lng`・`memo`。韓国は `kr`(韓国語の名前。NAVER で探すのに使う)も
   - 移動や自由時間(印なし): `type: "move"`・`icon`・`time`・`end`・`name`・`memo`
   - 電車の移動には `stations` に乗り降りする駅を入れる(`name`・`kr`・`role`("乗る" / "降りる" / "乗り換え")・`lat`・`lng`。バス停は `icon: "🚌"`)。そのカードを選ぶと地図に駅が出て、カードに駅の NAVER ボタンが付く
   - 座標があやしい所は `googleQuery` に住所を入れると、Google マップは住所で探す。`note` は小さく出る注意書き
   - `memo` は「。」で文が分かれ、「→」でつなぐと番号つきの手順になる
   - **電車かタクシーが要る移動で、電車で行ける時は、必ず電車の行き方を移動カードに全部書く**(Taku の希望):
     - `memo` に「→」でつないだ手順を書く: どこから乗る駅まで歩くか(分)→ 何号線(色)の何方面に乗るか(韓国語の方面名も)→ 何駅目のどの駅で降りるか・乗り換えるか → 降りた駅から目的地まで歩く(分)。わかれば出口番号も。最後にタクシーの目安も添える
     - `stations` に乗る駅・乗り換える駅・降りる駅を全部入れる(地図に駅が出て、駅ごとの NAVER ボタンが付く)
     - 調べきれない所(出口番号・駅数・所要時間)は確かめられていないと Taku に伝える
3. 並びは時刻の順。印の番号 `no` は場所のある予定だけに 1 から順に振り直す
4. 保存したら、JSON がこわれていないか確かめてから、`main` にコミットして push する。1〜2分でページに反映される(ページは再読み込みする)
5. 変えた所を、日本語で短く Taku に伝える

## そのほか

- ホーム画面のアイコンは `apple-touch-icon.png`(180×180。元の絵は `icon.svg`、黒地に白いピン(真ん中が TakuVLOG の黄色)・白い飛行機・黄色い点線。iPhone のダークのホーム画面では大きな色の面が暗くされ、白と細い色は残るので、この形にしている。絵を変えたら index.html の `?v=` の数字も上げる(Safari が前の絵を覚えているため))。名前は「トラベラー」(`<title>`・`apple-mobile-web-app-title`・`manifest.json` の3か所。iPhone はページの名前を使うことがある)。変えた時は、iPhone のホーム画面のアイコンを消して Safari から「ホーム画面に追加」し直さないと古いまま

- AutoPrep(`~/Movies/AutoPrep/TELOP/place_cards.py`)が Vlog の場所の札をつくる時に `data/` の下の JSON を全部(サブフォルダも)読んでいる。`items` の `name`・`kr`・`googleQuery`・`time` の形は変えない

- 地図のライブラリは Leaflet 1.9.4 に固定(cdnjs)。キーは不要
- 時刻は日本・韓国とも +9時間として「今ここ」を出す
- 「今ここ」(2026-11-21〜): その日を見ている時は、まず**現在地(GPS)から 400m 以内のいちばん近い予定**を出す(同じ場所が何度もあれば時刻が今に近い方。`hereIndex`)。現在地が分からない・近くに予定がない(移動中など)時だけ、時刻で「いまの予定」を出す(`nowIndex`)。時間どおりに動けていない日でも、実際にいる所のカードが出るように。地図には**自分(青い点)とそのカードの場所が両方入る**ように寄せ、「いちばん近いのは④ ○○(約300m)」と知らせる(縮めて見れば、どの番号が近いか分かる)。現在地がまだ分からない時は GPS を始め、最初に取れた所で1回だけ寄せる(`showMeAndCard`)
- 韓国では Google マップの徒歩・車のナビが使えないので、NAVER のボタンを大きくしている

## 交通費の見積もり(右上の ⋯ → 便利メニュー)

入っている予定を、となりの場所どうし電車・バスで動いた時の料金のめやすを出す(交通系 IC カードにいくらチャージするかの目安。2026-11-17)。

- 区間ごとの一覧(歩く・地下鉄・バス・空港バス)と、1日ごと・全体の合計。合計は「下=予定どおり/上=予定にないホテルへの帰り(1日1回)+3割増し」の幅で、ウォンと円
- 飛行機・車・タクシー・ケーブルカーは数えない。800m 未満は歩く(0)。予定のメモに「17,000ウォン」のように書いてあれば、その料金を使う
- 料金の決まり・円のレート・出どころは `data/fare_rules.json`。料金が変わったらここを直す(いまは韓国だけ。ほかの国は「料金の決まりがありません」と出る)
- 「コピー」で一覧を文字にできる
- 便利メニューは、これから機能を足していく入口
