# TakuVLOG トラベラー(旧: 旅のしおりマップ)

旅行の予定カードと地図(OpenStreetMap)が連動する1枚のページ。GitHub Pages で公開している。旅行をいくつもためて、左上のプルダウンで切りかえる(過去の旅行も、これから行く旅行も)。

- `index.html` … ページ本体。データを読んで表示するだけ(ふだんは触らない)
- `data/trips.json` … 旅行の一覧(`id`・`name`・`start`・`end`)。左上のプルダウンに出る
- `data/trips/<id>/day1.json`, `day2.json` … その旅行の日ごとの予定。日を足す時は次の番号のファイルを作る。番号は1から飛ばさずに続ける。ファイルがまだない日は、`start`〜`end` から空の日として出る
- 開いた時に出る旅行: 旅行の日ならその旅行 → これから行くいちばん近い旅行 → 最後に見た旅行。リンクは `?trip=<id>&day=day2`。前のリンク(`?day=day2` だけ・何もなし)もそのまま開ける
- 右上の ＋ … 行き先・日にち・名前・行きたい所を入れると、その端末の中だけに「下書き」の旅行ができる(すぐ選べる)。下書きの「Claude に頼む文をコピー」を Claude Code に貼ると、下の「旅行を足す時」の手順で公開の旅行になる。同じ名前・同じ1日目の旅行が `trips.json` に入ると、下書きは自動で消える
- 地図に自分の位置(GPS)を青い点で出す。旅行の当日は開いた時から、ほかの日は地図右上の 📍 を押した時から。📍 を押すと自分の位置へ移動する
- 韓国の場所のある予定には「ここへ行く」の 🚶徒歩/🚇電車・バス/🚕タクシー ボタンが出る。時間は現在地(なければ1つ前の予定)からの直線距離で出した目安。押すと NAVER の経路がその手段で開く。おすすめは 1.2km まで徒歩、15km まで電車・バス
- 場所のある予定には「✓ 行けた/行けなかった」ボタンが出る。旅行の当日は、GPS で予定の場所から 150m 以内に入ると、いちばん近い1つを自動で「行けた」にする(マップを開いている間だけ)。記録はその端末だけに残り、上の帯から全日の一覧を出してコピーできる
- 旅行の当日は、カードに「ここから再開」ボタンが出る。押すとそのカードを今の時刻にして、後ろの予定も同じだけずらす(飛ばした予定はそのまま)(その iPhone の中だけに覚える。データの JSON は変わらない)。上の帯を押すと元に戻る
- ページ上部に日の切りかえが出る。旅行の当日は、どのリンクから開いても今日の日を出す。上の日付ボタンで選び直した時だけ、その日を出す。旅行の日以外は、その旅行で最後に見た日を出す

## 旅行を足す時(Claude へ: この手順で)

1. 作業の前に必ず `git pull`(iPhone の Claude Code から直接コミットされることがある)
2. `data/trips.json` の `trips` に1件足す: `id`(`2027-05-korea` のように 年-月-行き先 の英小文字。あとで変えない)・`name`(「2027年5月 韓国旅行」のように。下書きから頼まれた時は下書きと同じ名前)・`start`・`end`("2027-05-02" の形)
3. `data/trips/<id>/` を作り、`day1.json` から日ごとに入れる(形は下の「予定を変える時」と同じ。`title` は「韓国旅行 1日目」、`date`・`weekday`・`utcOffset`・`items`)。予定が決まっていない日は作らなくてよい(空の日として出る)
4. 予定は行き先を調べて、案を Taku に見せてから入れる
5. JSON がこわれていないか確かめて、`main` にコミットして push

## 予定を変える時(Claude へ: この手順で)

1. 変えるのは `data/trips/<id>/dayN.json`(と旅行の日にちが変わる時は `data/trips.json`)だけ。`index.html` は触らない
2. 1件の形:
   - 場所のある予定: `no`(印の番号)・`time`("16:30" の形)・`name`・`country`("jp" / "kr")・`lat`・`lng`・`memo`。韓国は `kr`(韓国語の名前。NAVER で探すのに使う)も
   - 移動や自由時間(印なし): `type: "move"`・`icon`・`time`・`end`・`name`・`memo`
   - 電車の移動には `stations` に乗り降りする駅を入れる(`name`・`kr`・`role`("乗る" / "降りる" / "乗り換え")・`lat`・`lng`。バス停は `icon: "🚌"`)。そのカードを選ぶと地図に駅が出て、カードに駅の NAVER ボタンが付く
   - 座標があやしい所は `googleQuery` に住所を入れると、Google マップは住所で探す。`note` は小さく出る注意書き
   - `memo` は「。」で文が分かれ、「→」でつなぐと番号つきの手順になる
   - **電車かタクシーが要る移動で、電車で行ける時は、必ず電車の行き方を移動カードに全部書く**(Taku の希望):
     - `memo` に「→」でつないだ手順を書く: どこから乗る駅まで歩くか(分)→ 何号線(色)の何方面に乗るか(韓国語の方面名も)→ 何駅目のどの駅で降りるか・乗り換えるか → 降りた駅から目的地まで歩く(分)。わかれば出口番号も。最後にタクシーの目安も添える
     - `stations` に乗る駅・乗り換える駅・降りる駅を全部入れる(地図に駅が出て、駅ごとの NAVER ボタンが付く)
     - 調べきれない所(出口番号・駅数・所要時間)は確かめられていないと Taku に伝える
3. 並びは時刻の順。印の番号 `no` は場所のある予定だけに 1 から順に振り直す
4. 保存したら、JSON がこわれていないか確かめてから、`main` にコミットして push する。1〜2分でページに反映される(ページは再読み込みする)
5. 変えた所を、日本語で短く Taku に伝える

## 公開してはいけないもの(必ず守る)

このページはリンクを知っていれば誰でも見られる。

- 自宅の位置・住所(「自宅を出発」は座標なしのカードにする)
- 駐車場などの予約番号
- 個人のフルネーム・メールアドレス

## そのほか

- ホーム画面のアイコンは `apple-touch-icon.png`(180×180。元の絵は `icon.svg`、黒地に白いピン(真ん中が TakuVLOG の黄色)・白い飛行機・黄色い点線。iPhone のダークのホーム画面では大きな色の面が暗くされ、白と細い色は残るので、この形にしている。絵を変えたら index.html の `?v=` の数字も上げる(Safari が前の絵を覚えているため))。名前は「トラベラー」(`<title>`・`apple-mobile-web-app-title`・`manifest.json` の3か所。iPhone はページの名前を使うことがある)。変えた時は、iPhone のホーム画面のアイコンを消して Safari から「ホーム画面に追加」し直さないと古いまま

- AutoPrep(`~/Movies/AutoPrep/TELOP/place_cards.py`)が Vlog の場所の札をつくる時に `data/` の下の JSON を全部(サブフォルダも)読んでいる。`items` の `name`・`kr`・`googleQuery`・`time` の形は変えない

- 地図のライブラリは Leaflet 1.9.4 に固定(cdnjs)。キーは不要
- 時刻は日本・韓国とも +9時間として「今ここ」を出す
- 韓国では Google マップの徒歩・車のナビが使えないので、NAVER のボタンを大きくしている
