# 旅のしおりマップ

旅行の予定カードと地図(OpenStreetMap)が連動する1枚のページ。GitHub Pages で公開している。

- `index.html` … ページ本体。データを読んで表示するだけ(ふだんは触らない)
- `data/day1.json`, `data/day2.json` … 日ごとの予定。日を足す時は次の番号のファイル(`day3.json` など)を作る。番号は1から飛ばさずに続ける
- 2日分以上あると、ページ上部に日の切りかえが出る。URL に何も付けずに開くと、旅行の当日ならその日、それ以外は1日目を出す(`?day=day2` で日を指定もできる)

## 予定を変える時(Claude へ: この手順で)

1. 変えるのは `data/dayN.json` だけ。`index.html` は触らない
2. 1件の形:
   - 場所のある予定: `no`(印の番号)・`time`("16:30" の形)・`name`・`country`("jp" / "kr")・`lat`・`lng`・`memo`。韓国は `kr`(韓国語の名前。NAVER で探すのに使う)も
   - 移動や自由時間(印なし): `type: "move"`・`icon`・`time`・`end`・`name`・`memo`
   - 座標があやしい所は `googleQuery` に住所を入れると、Google マップは住所で探す。`note` は小さく出る注意書き
   - `memo` は「。」で文が分かれ、「→」でつなぐと番号つきの手順になる
3. 並びは時刻の順。印の番号 `no` は場所のある予定だけに 1 から順に振り直す
4. 保存したら、JSON がこわれていないか確かめてから、`main` にコミットして push する。1〜2分でページに反映される(ページは再読み込みする)
5. 変えた所を、日本語で短く Taku に伝える

## 公開してはいけないもの(必ず守る)

このページはリンクを知っていれば誰でも見られる。

- 自宅の位置・住所(「自宅を出発」は座標なしのカードにする)
- 駐車場などの予約番号
- 個人のフルネーム・メールアドレス

## そのほか

- 地図のライブラリは Leaflet 1.9.4 に固定(cdnjs)。キーは不要
- 時刻は日本・韓国とも +9時間として「今ここ」を出す
- 韓国では Google マップの徒歩・車のナビが使えないので、NAVER のボタンを大きくしている
